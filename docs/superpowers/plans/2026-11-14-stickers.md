# WeChat Native Sticker Implementation Plan

**Goal:** Implement SPEC v1.1 for plugin v0.3.15 against Native v2.4.0.
**Spec:** `docs/SPEC-WeChat Native Sticker Receive Save  Send.md`.
**Architecture:** Reuse NativeClient media validation/jobs, adapter media handoff,
send_chain lock/outbox/loop protection, trusted tool context and StateStore.
No parallel sender, media service, catalog database or background sync.

## Review focus

- Revocation/recall and event scope changes during awaits must prevent submission.
- Unknown outcomes and process cancellation must retain blocking durable intent.
- Failed/changed Job identity must never be accepted as success.
- A phone-side Saved deletion must invalidate membership despite prior success.
- Config off must leave existing behavior and HTTP traffic unchanged.
